# VK Bot ЯЛОН

Бот для сообщества ВКонтакте, который собирает рекомендации локальных авторов и анкеты для фокус-групп.

## Возможности

- Приём рекомендаций авторов (VK, Telegram, Instagram, TikTok)
- Нормализация ссылок и подсчёт упоминаний
- Пошаговая анкета фокус-группы
- Сохранение всех данных в Google Sheets
- Админ-команды `/stats` и `/export`
